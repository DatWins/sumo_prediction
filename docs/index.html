How the model works

The model predicts the winner of each individual Makuuchi bout using a LightGBM binary classifier trained on ~39,000 bouts from 2000–2023. It outputs a win probability for each rikishi, and picks the one with the higher probability.

Data sources

Bout results, banzuke, and rikishi stats pulled from sumo-api.com (which wraps SumoDB). Kimarite data complete from 1991. Banzuke and results go back to 1757, with daily results from 1909.

Yaocho note: Day 15 bouts involving a 7-7 rikishi show statistically anomalous win rates consistent with match-fixing evidence in the literature. These bouts are flagged but included in training.

Realistic accuracy ceiling for individual bout prediction is 65–70%. Sumo has genuine randomness — favourites lose regularly.
